# Jungle Ride

Jungle Ride is a small procedural cycling game for Android, built with Unity 2022.3.62f1. The road, jungle, bike, rider, obstacles, lighting, and mobile controls are generated by C# at runtime; no third-party art package is required.

## Repository layout

- `Assets/Scripts/` — runtime world, rider, and procedural mesh code.
- `Assets/Editor/JungleBuild.cs` — editor preparation and Android build entry point.
- `.github/workflows/build-android.yml` — reproducible GitHub Actions APK build.
- `Packages/manifest.json` — Unity module dependencies.

The editor build script creates `Assets/Scenes/Main.unity` and `Assets/Resources/JungleBase.mat` when the project is prepared or built. They are generated files and are intentionally not required in source control.

## Local Unity build

Install Unity `2022.3.62f1` with Android Build Support, Android SDK & NDK Tools, and OpenJDK. Open this repository as a Unity project, then use **Jungle Ride → Prepare Project**. To build locally, use **Jungle Ride → Prepare Project** followed by the Android build command, or invoke `JungleBuild.BuildAndroid` from batch mode.

The configured application identifier is `com.appforge.jungleride`. The build targets Android API level 24+ and ARM64, and produces `build/Android/JungleRide.apk` by default.

## GitHub Actions APK build

The workflow can be started manually from **Actions → Build JungleRide Android APK → Run workflow**. It also runs when gameplay, Unity package/project settings, README, or workflow files are pushed to `main`.

Configure these repository Actions secrets before the first build:

- `UNITY_LICENSE` — the complete contents of a Unity personal or professional license `.ulf` file.
- `UNITY_EMAIL` — the Unity account email associated with the license.
- `UNITY_PASSWORD` — the Unity account password associated with the license.

The workflow uses GameCI with Unity `2022.3.62f1`, calls `JungleBuild.BuildAndroid`, and uploads the resulting APK as an artifact named `JungleRide-APK-<run number>`. Download it from the completed workflow run under **Artifacts**.

Do not commit Unity credentials, license files, keystores, passwords, or signing keys. The workflow currently produces an installable debug APK. A release-signed APK requires a separate Android keystore stored as encrypted GitHub secrets.

## Controls

- Touch buttons: steer left/right, pedal, and brake.
- Keyboard fallback: Arrow keys or `A/D/W/S`; Space also brakes.
- Hold brake while stopped to roll backward slowly.

## Current scope

This is a playable prototype focused on the ride loop and procedural environment. Menus, sound, scoring, progression, save data, and release signing can be added as subsequent features.
